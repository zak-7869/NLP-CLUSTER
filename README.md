# NLP Cluster

## Description

This project implements natural language processing (NLP) text clustering using machine learning techniques. It groups similar text documents together without predefined labels.

## Installation & Setup

### Prerequisites
- Python 3.8+
- pip or conda
- Scikit-learn
- NLTK
- NumPy, Pandas, Matplotlib

### Steps

1. Clone the repository:
```bash
git clone https://github.com/zak-7869/NLP-CLUSTER.git
cd NLP-CLUSTER
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter:
```bash
jupyter notebook
```

## Usage

1. Open notebooks:
```bash
jupyter notebook
```

2. Load text documents

3. Preprocess text

4. Apply clustering algorithms

5. Analyze and visualize clusters

## Technologies Used

- **Scikit-learn**: Clustering algorithms
- **NLTK**: Text processing
- **NumPy/Pandas**: Data handling
- **Matplotlib**: Visualization
- **Word2Vec/GloVe**: Text embeddings
- **Jupyter Notebook**: Interactive environment

## Clustering Methods

- K-Means
- Hierarchical Clustering
- DBSCAN
- Gaussian Mixture Models
